# Managing Applications

The Applications section gives local authority staff a central view of all submissions for the current school year. From here you can create new applications on behalf of families and run the automated placement-matching process.

## Applications Toolbar

At the top of the Applications list you will find two action buttons:

<div style={{display: 'flex', gap: '0.5rem', marginBottom: '1.5rem'}}>
  <button className="button button--primary">New Application</button>
  <button className="button button--primary">Run Matching</button>
</div>

| Button | Purpose |
|---|---|
| **New Application** | Opens the form to manually create an application on behalf of a family. |
| **Run Matching** | Starts the automated algorithm that matches submitted applications to available placements based on your eligibility and priority rules. |

## Creating a New Application

1. Click **New Application** in the toolbar.
2. Search for the child or parent/carer record, or create a new one.
3. Complete the application form and submit.

The application will appear in the list with a **Pending** status until matching is run.

## Running Matching

Running matching processes all pending applications against available spaces, applying the priority and eligibility rules configured in Settings.

1. Click **Run Matching** in the toolbar.
2. Confirm the action in the dialog that appears.
3. Wait for the process to complete — a summary of offers, refusals, and waitlist positions will be displayed.

:::caution
Running matching will update the status of all pending applications. This action cannot be undone.
:::
